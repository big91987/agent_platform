# 架构诊断评分实施计划

按用户已确认的方向实现，直接在当前会话完成，不提交测试仓改动。

**目标：** 报告提供可解释的架构评分、规则违规数、评审完整度，并对两个指定仓库运行检查。

**评分约定：** 七个基础维度等权。符合为 100，低／中／高严重度分别为 80／50／0；同一维度取最严重档，不按发现条数累扣。明确依赖规则违规将依赖分工维度限制为 0，仍保留原规则门禁。证据未核验、缺少维度、存在阻塞或检查未完成时不输出总分。不适用有说明并排除分母；七项全不适用不能得到总分。额外场景检查单列，不改变基础评分权重，但未完成仍阻止总分。

**依据：** 每个扣分展示严重度、具体发现、源码引用与理由。评分是模型架构判断的量化，不表示业务验收结果或跨项目效率。
