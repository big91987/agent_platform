# Agent Platform Implementation Plan

> For agentic workers: use superpowers:executing-plans. User authorized architecture decisions and continuous implementation; no further design approval checkpoint.

Goal: provide a usable local generic Agent platform with real Codex, durable API/browser conversations and observable recovery.
Architecture: one Go HTTP process, SQLite transactional input and events, isolated persistent conversation directories, bounded local processes.
Tech stack: Go 1.25, database/sql + go-sqlite3, TOML parser, embedded HTML/CSS/JS.
Spec: docs/01-product/prd.md; docs/02-architecture/architecture.md.

## Global constraints

Same-machine only. Single Agent first. Codex first. No fixed development stages, external queue, distributed worker, silent session replacement or automatic uncertain replay. Secrets and local histories stay in .data. Native Skills retain progressive disclosure.

## Review focus

Cross-source ownership; stop racing process start; interruption/restart with partial events; repeated input with changed content; artifact traversal/symlinks and UI injection.
