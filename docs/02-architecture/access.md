# 用户、调用方与会话访问

## 身份和边界

- 管理员账号：管理 Agent、调用方凭据、用户与平台会话。
- 调用方凭据：绑定来源及 Agent 范围，API 提供该来源内的稳定 user_id。
- 调用方用户账号：绑定一个调用来源与 user_id，不能自行切换身份，只访问自己的会话；不读取 Agent 私有配置。
- 临时会话入口：调用系统签发一个会话的有限时授权。不是新的 Agent 实例，也不携带 API 凭据。持链接者可查看、回复、停止与关闭这段会话，不得访问其他会话、创建新会话或继续签发链接。

用户以 username 识别，不额外增加用户代理 ID。调用来源继续复用 credentials.id；原生 thread_id 保留在平台内部。

用户密码采用带随机盐的 PBKDF2-SHA256（100000 轮），不返回密码或哈希。账号保存会使旧登录失效；每次请求和 SSE 重读账号与调用凭据启用状态。浏览器登录持久保存在 SQLite，重启后继续生效，受原始有效期限制。

## 临时链接

1. Runner 以原 API 凭据调用 POST /api/conversations/{id}/web-access，传 user_id 与 expires_in。
2. 平台核对原会话归属，返回 conversation_id、expires_at、url。默认 1 小时，允许 60–86400 秒。
3. token 只放在 URL fragment 中，打开页面时兑换 HttpOnly、SameSite=Lax Cookie，然后移除 fragment。
4. 授权信息仅保存 token 哈希，并绑定来源、user_id、会话和失效时间。浏览器会话期限不超过原链接授权期限。
5. 原调用方被禁用、授权到期或会话删除后不能再使用。刷新不丢失授权；平台重启不会延长授权。

这是有时效的持有者授权链接，不认证 GitHub 账号。调用系统应交给会话发起者；当前实验使用 GitHub Issue 显示链接，知道链接的读者同样拥有该会话授权。后续需要身份核验时接入外部登录，不能把临时 token 描述成已经验证过发起者身份。

## 网页与 API 接续

公开 conversation_id 锚定一个 Agent 的持久会话。初次 API 请求省略它，平台创建独立工作区和原生历史；已有会话打开或回复都复用同一记录。每轮原生进程可退出，后续调用显式 resume 已保存 thread_id。

管理界面参考 saibotan 与 sifamily 的浅色侧栏、蓝色主操作及管理和聊天分区：Agent 卡片进入该 Agent 的会话列表，调用方、用户、API 文档是独立导航。调用方网页只有自己的会话和产物，不显示配置管理菜单。原始事件和工具过程保持累加、可折叠。

## 默认管理员口令

本地实验首次启动默认 admin/admin，可用 AGENT_PLATFORM_PASSWORD 设置自定义初始口令。管理员账号持久化后，重启不会覆盖已有密码；后续通过用户管理修改。内置 admin 允许用户指定的 admin 口令，其他用户密码仍要求 12–256 字符；更换密码立即使该账号旧登录失效。
