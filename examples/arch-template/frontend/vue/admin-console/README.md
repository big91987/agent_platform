# Vue 管理控制台

本场景面向多页面管理控制台，按业务功能组织页面、组件、交互状态和接口访问。可连接 Go、Java、Python 等后端，通过目标项目的 API 契约连接，不依赖后端目录、数据库或指定框架。

建议采用 Vue 3、TypeScript、Vite 和单文件组件；共享状态确实需要时再采用 Pinia。可运行配额查询样板、规则与异步状态测试见 [template](template/AGENTS.md)。共同要求见[通用原则](../../../principles.md)和[工程校验与验收](../../../verification.md)。

## 代码与职责

```text
src/
  app/                          启动、路由及会话接入
  features/                     按目标项目业务组织
    tenants/                    租户、成员示例
    keys/                       Key 管理示例
    models/                     模型配置示例
    usage/                      用量、账单示例
  shared/
    ui/                         无业务组件
    api/                        HTTP 传输、取消和统一错误处理
```

这些 feature 是当前 MaaS 验证使用的示例，其他管理产品按实际业务替换。每个 feature 按需要增加 pages、components、composables、api.ts 和 types.ts，没有相应职责就不创建空目录。

| 内容 | 职责 |
| --- | --- |
| 页面与组件 | 页面组合、展示、输入及事件；避免整个控制台集中在一个组件 |
| composable | 本次操作的异步状态、草稿、请求取消、错误恢复及读回完成 |
| feature API | 模块专属接口及类型，保留服务端金额、可空值、版本和错误语义 |
| shared API | 通用传输、会话／CSRF 接入和 AbortSignal，不承担模块业务判断 |
| 规则函数 | 可独立验证的展示转换和前端校验；服务端继续执行权限及业务约束 |

feature 之间通过公开入口使用能力，不跨模块引用内部文件。shared 不依赖 features；局部状态归当前组件或 composable，只有确实跨页面共享的状态进入应用级 store。

## 交互、接口与构建

- 页面覆盖加载、空数据、成功、失败和权限受限状态。保留草稿、重复提交限制、失败后重试及读回失败后的适当恢复。
- 切换租户、对象或会话后，取消请求并阻止失效结果覆盖当前界面。提交成功对应本次响应、适用的读回和视图完成，不能依据旧提示或弹窗关闭判断。
- 一次性秘密按业务要求展示和清理，不进入日志、URL 或持久化的通用状态。接口类型不替代运行时边界检查或服务端授权。
- 保留键盘可达、焦点、弹窗关闭、窄屏局部滚动和根页面无异常横向溢出。响应式更新不替代真实浏览器验证。
- 部署基路径、API 地址、会话和错误契约由目标项目明确配置，不写死某个后端端口。API 路径不能被 SPA 回退为 HTML。
- 生产产物由正式构建生成；缺少或过期产物应报错，不能静默使用旧文件。静态托管或后端内嵌由组合项目确定，开发服务器成功不等于正式页面可用。

## 校验与工具候选

| 要求 | 校验方式 |
| --- | --- |
| shared 不依赖 features，跨 feature 不越过公开接口，网络访问归声明的 API 层 | TypeScript／Vue 分析提供事实，由统一架构规则判定；证明相对路径、别名、单文件组件和类型导入的覆盖 |
| 组件、脚本、类型、格式及生产构建正确 | ESLint、vue-tsc、格式工具和 Vite；转译通过不能代替类型检查 |
| 草稿、重复提交、读回、失败恢复和迟到响应正确 | Vitest、Vue 组件测试，断言可观察行为 |
| 实际权限、接口、键盘和布局正确 | Playwright 对所选后端及生产前端产物执行真实旅程；Mock 单独标明 |

前端依赖分析器、TypeScript 及 Vue 编译信息可以作为事实来源候选；ESLint 和 vue-tsc 继续负责各自的代码与类型规则。不能把支持语法解析当成依赖解析完整，也不能为 Vue 维护与后端含义冲突的架构规则体系。

参考：[Vue 工具链](https://vuejs.org/guide/scaling-up/tooling.html)、[create-vue](https://github.com/vuejs/create-vue)、[Vue 测试指南](https://vuejs.org/guide/scaling-up/testing.html)。统一架构校验的复用评估和工具安装组合尚未验证。
